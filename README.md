## 美国云服务器推荐先看什么

线路是第一道分水岭。同样在洛杉矶，走 CN2 GIA（电信 59.43 回程）、AS9929（联通精品网）、CMI 或 CMIN2（移动）的机器，晚八点到十一点基本不掉速；走 NTT、GTT、CU4837 这类国际 Tier1 的，对大陆方向不做优化。后者常配 1Gbps 带宽，适合不依赖国内访问的业务。六六云把这两类分开卖，下单前先认这个差别，不要只看价格和内存。

IP 属性是第二道。原生 IP 是当地运营商分配的地址，归属地干净；双 ISP 指机房托管但 IP 库将其识别为运营商住宅用户；家宽 IP 更彻底，ASN 直接挂在 AT&T 这类宽带运营商名下。跑 TikTok、开跨境电商店铺、看美区流媒体、登 ChatGPT，平台风控主要检查的就是这一层。纯建站、访客只是打开网页看内容，这一层不重要，把钱花在优化线路上更值。

延迟可以对照几个数。西海岸（洛杉矶、圣何塞、西雅图）到国内，优化线路 150—180ms 属于优秀，普通国际线路 190—230ms 属于正常，超过 250ms 基本就是绕路了。东海岸机房普遍比西海岸多 50ms 以上，主打国内访问不必考虑。六六云美国线全在洛杉矶，方向是对的，官方在 CN2 GIA 那条线给出了测试 IP `154.36.135.254`，下单前自己 ping 一遍，比看任何测评都准确。

最后两件事：美国服务器不受国内备案约束，买完做好解析就能开站，内容按当地法律和版权规则来；价格上注意月付价乘 12 不等于年付价，年付通常更便宜，另外很多商家首单便宜、第二年涨价。六六云的服务条款第 2.4 条写着“优惠码与活动价在后续续费中继续有效”，这条比折扣本身更值钱。

## 短板和不适合的人

最需要提前知道的是：**IP 被墙不算故障，不退钱。** 服务条款第 5.3 条原文是“除 5.2 的一次性保证外，我们不对 IP 在任何特定网络（包括中国大陆）下的持续可达性作出承诺。IP 因运营商、上游网络或其他我们不可控的原因被屏蔽、丢包或不可达，不属于服务故障，不构成退款理由。”官方公告里也反复出现“墙高峰”的提示，其中一条写得很直白：“最近不少用户遇到服务器 Ping 得通，但 SSH 或业务端口连不上的情况，主要表现为 TCP 连接在中国大路段受限。”

换 IP 也不是免费的。除了开通后 1 小时内的一次免费机会，之后按配置价格收费，而且有次数限制：每台服务滚动 72 小时最多成功换 1 次，每个流量重置周期最多 2 次，每个账户每个自然月合计最多 5 次。碰上大范围 IP 被封的时期，官方还有权暂停换 IP 服务。做大陆访问的业务，这条要算进风险成本。

第二件事是**没有备份**。条款第 7.1 条写得很清楚：“我们不提供数据备份服务，服务器未配置数据冗余。请务必自行做好异地备份。”公告里也能看到真实案例：美国 US4 节点物理服务器硬件故障，存储介质物理损坏，其上实例的磁盘数据无法恢复；GTT 部分服务器硬件故障后同样是“数据无法恢复，系统已重装，平台补偿 3 天时间”。补偿方式是延长服务期或按剩余周期退款，不承担数据价值和业务中断损失。自己不做异地备份，出一次事故就是全部重来。

第三件事是**不管运维**。技术支持只管宿主机故障和开通、重启、重装、网络这类平台层问题，不代装面板、不代配环境、不代排查应用故障。工单是唯一正式支持渠道。会自己折腾 Linux 的人无所谓，指望买完有人帮你把网站搭起来，这里不合适。

退款规则也要看清：超过 48 小时不再受理，促销、特价、活动产品和预售产品不支持退款，每台服务器只受理一次退款，同一个支付账户 3 天内最多退一台，续费订单不退。

所以以下几类人不建议买：需要 SLA 和故障赔付的企业业务；把大陆方向可达性当硬指标、断一天就出事的业务；完全不懂服务器、需要人代维的；需要多 IP 或者 Windows 授权捆绑的。这些需求去找大厂或者带托管服务的商家更省心。

## 常见问题

### 美国云服务器需要备案吗？

不需要。服务器在美国，不受国内备案政策约束，买完直接解析域名就能开站。内容仍然要守版权和当地法律，被投诉一样会停。

### 支持支付宝吗？

支持。需要注意续费逻辑：官方不代扣支付宝，自动续费只从账户余额里扣，到期前要先往账户里充值，否则余额不足就按到期处理，服务会暂停，而且暂停期间照常计费。

### 洛杉矶机房延迟多少算正常？

优化线路 150—180ms 是好水平，190—230ms 属于普通国际线路的正常范围，超过 250ms 要怀疑绕路。六六云官方给了 CN2 GIA 的测试 IP `154.36.135.254`，用自己的网络 ping 一轮，比看别人的图更靠谱。

### IP 被墙了能退款或者免费换吗？

不能退款，条款里明确写了 IP 在特定网络下不可达不属于服务故障。换 IP 除开通后 1 小时内的免费机会外都要收费，还有 72 小时 1 次、每流量周期 2 次、每账户每月 5 次的限制。官方在“墙高峰”公告里的建议是关机保 IP，或者调整传输方式降低被识别概率。

### 数据安全吗，需要自己备份吗？

需要，而且必须自己备。官方明确不提供备份服务、不配置数据冗余，磁盘阵列只是提升硬件可靠性，不等同于备份。历史上出现过节点硬件故障导致数据无法恢复的情况，补偿只是延长服务期。定时把数据同步到本地或另一个服务商，是使用这类低价美国服务器的基本操作。
